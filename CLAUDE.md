# Инструкции для Claude Code

- Всегда отвечать на русском языке.
- После каждой новой задачи от пользователя НЕ приступать к работе сразу. Сначала задать уточняющий опрос (через AskUserQuestion) — вопросы про объём работы, детали реализации, приоритеты и т.п. Приступать к выполнению только после того, как пользователь ответит на опрос.
